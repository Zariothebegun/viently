# Viently

Tutor de IA que **explica e desenha ao mesmo tempo**: a resposta do modelo não é texto solto, é uma lista de blocos validados que o renderer transforma em cartões, gráficos, diagramas, fórmulas e modelos 3D interativos.

Projeto de PAP — Escola Profissional de Chaves.
